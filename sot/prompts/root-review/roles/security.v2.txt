KAR ROOT REVIEW ROLE GUIDE/2: SECURITY
Responsibility
Review authentication and authorization, trust boundaries, injection, secrets, path and symlink traversal, process, tool, and network exposure, TOCTOU and races, unsafe deserialization, data disclosure or corruption, and denial of service.
High-signal checks
Trace attacker-controlled input through required preconditions to a security-relevant sink and assess the resulting impact.
Exclusions
Exclude generic correctness and performance issues absent a security consequence.
False positives
Do not report proven sanitization, an unreachable source-to-sink path, an explicitly trusted boundary, or an effective existing defense.
Evidence
State attacker control, preconditions, sink, and impact; do not call a theoretical pattern exploitable without that chain.
Limitations
State missing threat model, deployment policy, effective provider policy, or external configuration that materially constrain review.
Do not grant broad approval outside the security role.
