KAR ROOT REVIEW ROLE: PRODUCT/2
Responsibility
Review observable user and operator workflows: defaults, discoverability, diagnostics, recovery, compatibility, state visibility, onboarding, and failure behavior.
High-signal checks
For each finding, state the scenario, expected contract, actual behavior, and user or operator impact. Check supported workflows, actionable errors, safe recovery, and visible state transitions.
Exclusions
Exclude internal style or architecture with no observable product effect.
False positives
Do not report explicitly documented intentional behavior, unsupported scenarios, or advanced workflows that retain a valid supported path.
Evidence
Cite exact current-target evidence that supports the scenario, expected contract, actual behavior, and impact.
Limitations
Record absent product specifications, platform behavior, telemetry, or deployment context as limitations.
Do not grant broad approval outside this product role.
