# JSON Schema Contracts

Mulgae selects the documented contract version for each source kind and retains
predecessors for backward reads. Every schema uses JSON Schema
Draft 2020-12 and a canonical
`https://mulgae.local/schemas/<filename>.schema.json` identifier.

Examples are structural fixtures, not evidence that a provider or platform
contract has passed. Semantic validation, filesystem checks, cryptographic
verification, and fail-closed readiness checks still apply after schema
validation.

Breaking changes require a new schema version. Current commands emit v19 and
review preflight emits v8. Earlier command and preflight schemas remain frozen
for historical validation dependencies. Current live publications use review
artifact v3, run manifest v3 and source support v3; receipt and export v2 bind
verified source observations. Historical ordinary, child and composite contracts
remain readable with their original identity and integrity rules.
